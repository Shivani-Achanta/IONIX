# **Ionix** - EEE Department Hackathon Website

**Ionix** is a website designed for the EEE department's hackathon. It serves as a central hub for event details, registration, and other essential information. The website is built with HTML, CSS, and JavaScript to ensure a clean, interactive, and responsive user experience.

## **Features**
- Responsive design for all devices.
- Event details and registration information.
- Easy-to-navigate interface for participants.
- Interactive elements with JavaScript.

## **Tech Stack**
- **HTML**: For the structure of the website.
- **CSS**: For styling and layout.
- **JavaScript**: For interactivity and dynamic behavior.

## **Getting Started**

### 1. Clone the Repository
Start by cloning the repository to your local machine.

### 2. Run the Website
Once you've cloned the repo, open the index.html file in your web browser to see the website.

### 3. No Server Setup Required
The website is static and does not require a server setup. Simply open the index.html file in your browser to view the content.
